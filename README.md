# 8-Bit Vedic Multiplier Using Verilog HDL

Designed and implemented an 8-bit Vedic Multiplier using the Urdhva Tiryagbhyam (Vedic Mathematics) algorithm in Verilog HDL. The design follows a hierarchical approach by constructing larger multipliers from smaller Vedic multiplier modules and adders. Verified through simulation in Vivado.
